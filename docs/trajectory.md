# 轨迹视图

参考 DSH `ui-trajectory`，源码基准为 `c291e7961a515f6d7af9304e7fd1d257929aef26`。时间概览的序列/耗时投影与闲置时间压缩算法对应其 `timeline.ts`，许可证保留在 [DSH-LICENSE](third-party/DSH-LICENSE)。

在任务标题栏切换对话与轨迹。轨迹以轮次、助手步骤和工具父子关系组织记录，使用虚拟列表；首次显示最新 50 条，加载更早记录时保留阅读位置。搜索范围是当前已加载窗口，包含正文、工具参数、结果和模型信息；搜索命中会穿透折叠状态。选择记录可以查看输入输出、思考、模型、用量、计时、错误与图片。

- **耗时**：关闭时按操作顺序等宽展示；打开时按真实开始时间和已记录耗时投影，压缩空闲间隔，保留并发跨度。未记录开始时间的项不出现在耗时概览中。运行中的项只有开始标记，未记录耗时和 token 不冒充零。
- **轮次**：展开或折叠所有轮次，也可点击单个轮次控制。
- **工具**：展开或折叠助手下面的工具调用（包含嵌套子工具），也可单独控制助手。
- **概览操作**：滚轮/加减键缩放，左右键平移，左键拖选闭区间，点击标记定位记录；右键清除选区、右键拖动平移；重置恢复全域。
- **流式阅读**：默认跟随尾部；上滚或检查旧记录后暂停，点击“回到底部”或 End 恢复。新记录不会抢走阅读位置。

## 数据与接口

OMP JSONL 是持久会话事实来源，按当前叶子的 `parentId` 链投影，保留压缩和上下文项。工具通过 `toolCallId` 配对，不通过正文推测。消息通过 OMP 的角色/时间戳身份别名关联实时记录与持久 entry ID。

Host 在现有 observer 事件中附带变更轨迹记录，在 `TaskSnapshot.trajectory` 中保留当前运行的有界快照，断线后用完整快照恢复；普通分片不触发全文件读取。每次 OMP 消息或工具结束后，前端节流补读持久后缀。分页游标是稳定记录 ID，追加不会让更早页面的游标失效，分支变化导致失效时显式报错、允许重载。

- `task_trajectory(taskId, cursor?, after?)`：默认末尾 50 条；传 cursor 时向前读取，`after=true` 时从游标记录开始读取后缀（包含锚点的最新状态）。
- `task_trajectory_image(taskId, recordId, imageId)`：仅读取对应记录实际拥有的内联图片或 OMP Blob，支持 PNG/JPEG/GIF/WebP，单图最多 8 MiB。图片按需读取并在当前轨迹会话中缓存，远程 Markdown 图片不自动加载。

文件读取在阻塞线程中进行。当前文件限制 64 MiB，单行 16 MiB，文本字段 1 MiB，超限会报错或明确提示截断。实时快照保留最多 512 条、文本约 4 MiB；完整已结束记录由会话分页补回。

OMP 不提供的提供方请求头、工具 schema、历史工具开始时间等显示为未记录；Host 实际观测到的计时标注为 Host。OMP 没有落盘的子代理内部事件仅在当前运行快照中可见，持久工具结果保留子代理汇总。不会为追求字段齐全而构造不存在的事件或复制一套完整会话数据库。
